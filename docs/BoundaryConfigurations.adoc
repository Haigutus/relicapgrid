= Boundary Configurations in ReliCapGrid
:toc:
:toclevels: 2

== Overview

The ReliCapGrid project defines *6 cross-border AC and HVDC interconnections* between 7 fictional TSO areas (Galia, Belgovia, Svedala, Espheim, Nordheim, Britheim, Portheim), modelled in *CGMES v3.0* RDF/XML format.
All boundary configurations are provided as conformance test cases for CGMES boundary modelling tools, following ENTSO-E specifications (see link:https://eepublicdownloads.entsoe.eu/clean-documents/CIM_documents/Grid_Model_CIM/Boundary_and_reference_data_exchange_specification_v1.0.pdf[Boundary and Reference Data Exchange Specification v1.0]).

*Galia* acts as the central hub (3 borders). Together the borders form a partially meshed transmission network with ~20 individual boundary points, covering classical AC tie-lines as well as HVDC converter station boundaries.

* *Standard*: CGMES v3.0 (Common Grid Model Exchange Standard)
* *File locations*: `Instance/boundaryData/Grid/cimxml/`


== Boundary Point Modelling Approaches

The dataset demonstrates the following modelling patterns:

. *Separate boundary and common data* — independent datasets for distribution
. *Per-border datasets* — modular organisation by boundary


== Boundary types
. *AC Tie-Line Boundary* — classical approach with a ConnectivityNode splitting a tie-line
. *AC Substation Boundary* — two-point substation boundary configuration
. *HVDC boundary modelling* — bidirectional converter station boundary points with own IGM files
